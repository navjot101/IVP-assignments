## Folder structure

- `images/` - input photos used in the practicals (downloaded from picsum.photos)
- `videos/` - sample video for Practical 1
- `output/` - files saved by the notebooks
- `lab1.ipynb` to `lab10.ipynb` - practical notebooks

## How to run

Install the required packages:

```
pip install -r requirements.txt
```

Start Jupyter Notebook from this folder and open any practical notebook.
Run the cells from top to bottom.
